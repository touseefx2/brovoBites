1. System ka overview

Ye ek complete POS + admin system hai Brovo Bites ke liye. Browser mein chalta hai — alag app install nahi.

  • Admin panel — menu, staff, reports, expenses, inventory, cash drawer
  • POS — naya tab; order, checkout, 80mm receipt (branch + customer copy)
  • Public landing — customer domain par sirf menu / branches
Bilingual EN/Urdu · Cloud Firestore · Multi-branch · Global order numbers (#0001, #0002… sab branches milakar)

3. Dashboard

Aaj ki sales aur order count. Owner all branches; staff apni branch ke sab orders (owner wale bhi). Live listener — refresh ki zarurat nahi.

Open POS sidebar ke top gold button se naya tab khulta hai. Dashboard par alag POS/Orders buttons nahi.

4. POS

  1. Category / search se product
  2. Sized item par size choose
  3. +/− qty, optional kitchen note
  4. Checkout → dine-in / takeaway / delivery · cash / card / digital
  5. Optional discount · Confirm → 2 receipts
Drawer khula hona zaroori nahi — cash sale phir bhi save hoti hai. Expected cash drawer page par orders se calculate hota hai.

Tax % aur delivery charges checkout ke dauran lock ho jate hain (mid-ticket settings change se bill nahi badlega). Cart line price add ke waqt snapshot hoti hai.

5. Orders

Status model: completed ya cancelled. “Edited” / “Refunded” badges hain, alag status nahi.

  • Edit items → tax % dubara subtotal par, discount re-apply
  • Partial refund accumulate hota hai, remaining se zyada nahi
  • Cancel / delete completed order stock wapas (linked inventory)
  • Staff ki window (business day khatam hone tak, kam az kam 30 min) server time se — PC / phone ki clock se bypass nahi

6. Menu — ek tab

Add aur Edit naye tab mein khulte hain. Save ke baad pehli tab live update (BroadcastChannel, leak-safe cleanup).

7. Branches

Owner only. Staff ko ek branch assign. Staff doosri branch ka sales data nahi dekh / likh sakta.

9. Expenses

8 categories. Staff sirf aaj ki date par add (permission); apne kharche usi din edit / delete (permission). “Added by [name]”. Owner “All branches” par add karte waqt branch picker jo select kiya wahi save hota hai.

10. Inventory

From menu ya manual. Low-stock color. Purchase +stock, Waste −stock, Adjust = naya counted stock (barha ya ghata). Sale ke baad linked product auto-minus. Cancel/delete restock.

Bundle ke andar ke components alag se nahi kat-te — sirf deal product ka row (agar hai).

11–13. Reports

  • Item sales — qty + revenue; staff apne orders
  • Day report — sales, payment split, expenses expense date se, discounts, refunds, net. Owner staff breakdown
  • Cash drawer — open opening balance, close counted cash. Expected = opening + cash sales − cash expenses − cash refunds. Staff expected unke apne cash orders se

14–16. Discount, refund, receipt

Discount tax ke baad, delivery tax-free. Staff ki discount permission rules mein bhi check hoti hai. Refund: owner koi bhi order; staff sirf apna, usi business day (cancel permission). Reason zaroori, partial refunds accumulate. Receipt: shop, #, cashier, type, items+notes, tax, delivery, discount, total, payment, 2 copies.

17. Security — server-side

Ye client hide-button nahi. Firestore rules + owner-token APIs:
  • Staff sirf apni branch ke orders read (branch-scoped)
  • Staff update sirf apne order par, 24h server cap; refund sirf refund fields, total se zyada nahi
  • Discount permission check; order counter sirf aage barhta hai
  • Closed cash drawer staff rewrite nahi
  • Expense create createdBy bind + permission + aaj ki date
  • ImageKit upload/delete owner Bearer token

Roz check: Day report · Cash short · Extra cancels · Discounts · Expenses.
