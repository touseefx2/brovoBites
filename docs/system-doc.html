Brovo Bites POS

POS System Documentation · Monorepo bravoBites

Next.js + Firebase Auth + Firestore · Multi-branch ready

1) Kya bana hai / What was built

Web Point of Sale: counter pe order + bill print; owner pe menu, staff, branches, sales. Black/gold professional UI. Mixed English + Roman Urdu labels.

2) Roles

RoleAccess
Owner / AdminMenu, prices, staff create, branches, dashboard sales, orders history, POS
CounterPOS — cart, checkout, print. Apni branch ke orders, expenses, inventory (permissions ke mutabiq). No menu edit

3) Routes

PathPurpose
/loginEmail + password
/posCounter screen
/adminSales dashboard
/admin/branchesNew shop / branch
/admin/menuCategories & products
/admin/staffCreate counter users
/admin/ordersOrder history

4) Data model (collections)

  • branches — shop locations
  • users — role + branchIds
  • categories / products — menu (simple / sized / bundle)
  • orders / counters — sales + order numbers
  • settings — shop name, phone, tax, delivery charges, branding

5) Kaise run karein

  1. cd bravoBites && pnpm install
  2. apps/web/.env.local banao — Firebase keys paste (brovodev)
  3. Auth Email/Password enable + Firestore create + rules deploy
  4. Owner banao: pnpm create-owner -- --email=... --password=... --name=Owner --primary → UID copy
  5. Optional sample menu: pnpm seed -- --ownerUid=UID --ownerEmail=... --ownerName=Owner
  6. pnpm --filter web dev → http://localhost:3001
  7. pnpm test — domain unit tests

6) Multi-branch

Kal nayi dukaan: Admin → Branches → Add → Staff assign. Same app, alag branchId.

7) Print

Browser Print → thermal printer (USB/Wi‑Fi). ESC-POS v1 mein nahi.

8) Why not VPS

Firebase + Vercel/serverless hosting kaafi. Alag VPS abhi zaroori nahi.
